# Hinoki Learn

App ôn tiếng Nhật kiểu Anki (PWA) của Hinoki. Repo này chỉ chứa code và thẻ DEMO giả — không có dữ liệu học viên.

- Thuật toán lặp lại ngắt quãng: [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs) 6.0.0 (MIT), xem `vendor/ts-fsrs-LICENSE.txt`.
- Dữ liệu thật nằm trong Google Sheet riêng của Hinoki, kết nối qua Google Apps Script.
- Mở trang không kèm máy chủ = chế độ DEMO (HV01 / 1111, HV02 / 2222).
